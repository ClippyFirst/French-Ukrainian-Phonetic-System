# Французькі правила вимови

## Виконуваний рушій

Французька транскрипція використовує оригінальний rule-based parser OpenIPA, vendored під AGPL-3.0 у `vendor/openipa/`. Основний parser: `vendor/openipa/src/transcription/french/ParseFrench.ts`; його модулі включають контекстні парсери літер, `FrenchRules.ts`, `FrenchExceptions.ts`, `FrenchHelper.ts` і parse-functions.

Це не самописна імітація правил: браузерний adapter викликає скомпільований upstream parser. Збірка: `npm run build`.

## Підтримані upstream сімейства

- контекстні приголосні й буквосполучення: `c/ç, ch, g, gn, gu, qu, ph, th, x`, інтервокальне `s`, подвоєні приголосні;
- французькі голосні, діакритики, носові графеми, дифтонгоподібні послідовності й glides;
- кінцеві приголосні, schwa, окремі суфікси та префікси;
- словникові винятки: mer/ver-клас, фінальне -er, avoir, medial -ill, носові винятки, артиклі та інші окремі лексеми;
- text-level hooks для liaison та elision; у профілі вокальної дикції вони проходять через OpenIPA parser на повному тексті;
- оригінальні пояснення правил зберігаються в word-detail trace разом із source span та IPA.

## Профілі

- `metropolitan-fr` — виконує базовий OpenIPA parser без автоматичного liaison/elision аналізу. Це не незалежний повний рушій спонтанної розмовної французької.
- `lyric-diction-fr` — вмикає OpenIPA text-level liaison/elision options; кінцевий schwa та винятки відповідають upstream lyric-diction орієнтації.

## Важливі обмеження

- OpenIPA має власні TODO й неповне POS-залежне правило `-ent`; наш перенос не усуває upstream обмеження.
- OpenIPA legacy fixture `_words.csv` очікує `descends` → `d(e)sɑ̃`, але виконуваний parser наразі повертає `dɛssɑ̃`. Розбіжність зафіксована тестом і потребує розгляду; ми не підганяємо код під CSV.
- Upstream використовує `õ` та `ɾ`; `ε` нормалізується до `ɛ`, але `õ` не перетворюється на `ɔ̃` без фонетичного підтвердження.
- Проєктний seed lexicon та ручні IPA override видалено з runtime; усі слова обробляє OpenIPA.
- Власні назви, числа, абревіатури, запозичення, повна морфологія та регіональні варіанти не мають гарантії коректної обробки.

## Архітектурна межа

UFPN адаптер приймає тільки IPA. French G2P не має права напряму генерувати українські графеми. Невідомі IPA залишаються видимими й не вгадуються.
