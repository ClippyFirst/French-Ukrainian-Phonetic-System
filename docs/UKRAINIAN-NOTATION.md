# UFPN — Ukrainian French Phonetic Notation

**Статус:** експериментальна специфікація 1.1.0; не академічний стандарт.

UFPN — розширена кирилична практична фонетична нотація, а не система, обмежена українською абеткою. Дозволені графеми з білоруської, російської та інших кириличних традицій, якщо їхнє усталене звукове значення прозоро відповідає потрібному сегменту.

## Архітектурне рішення

Обрано гібридний варіант C: Basic → Detailed → Extended. Основою є читабельні кириличні графеми з української та інших кириличних абеток; діакритики використовуються лише для ознак, для яких немає стабільної окремої літери. У Extended додаються IPA-модифікатори лише тоді, коли вони вже присутні у вузькій транскрипції. Це не дозволяє вигадувати фонетичну точність із написання слова.

| Варіант | Переваги | Недоліки | Рішення |
|---|---|---|---|
| A. Українська графема + комбінована діакритика | компактність, Unicode, збереження якості голосних | залежність від шрифтів/клавіатури, складні стеки | використовується для основних контрастів |
| B. Надрядкові/підрядкові модифікатори | модульність, помітна артикуляційна функція | більше знаків, неоднорідне відображення | лише у Extended |
| C. Три рівні точності | навчальна читабельність і контрольована деталізація | треба пояснювати рівні | **обрано** |
| D. Тільки IPA | міжнародна точність | не виконує мету українського запису | лишається окремим канонічним шаром |

## Мінімальні базові діакритики та розширені модифікатори

| Знак | Функція UFPN | Приклад |
|---|---|---|
| ◌̊ | огублення переднього голосного/апроксиманта | і̊, е̊́, е̊̆ |
| ◌́ | напівзакрита якість середнього голосного | е́, о́ |
| ◌̆ | напіввідкрита якість середнього голосного | о̆ |
| ◌̠ | задніша/відсунута артикуляція | а̠ |
| ◌̃ | носовість голосного | ӗ̃, о̆̃ |
| ◌̇ | центральний редукований /ə/ | е̇ |
| ◌̌ | одноударний ротичний у регіональному allophone mapping | р̌ |
| ◌̯ | IPA-маркер нескладовості; не використовується для /w/, який має окрему графему | — |

У звичайному Basic залишаються лише ті знаки, які справді потрібні для контрасту або назальності (наприклад, `а̠`, `о̆`, `̃`, `ү̯`, `р̌`). Решта з каталогу — не обов'язкові прикраси: у Extended зберігаються лише стандартизовані фонетичні модифікатори, якщо вони вже присутні у вузькому IPA: ◌̬ дзвінкість, ◌̥ оглушення, ◌̟ висунення, ◌ʲ палаталізація, ◌ʷ лабіалізація, ◌̞ послаблення, ◌̝ підвищення/посилення фрикації.

## Розширений кириличний інвентар

UFPN свідомо не обмежується українською абеткою. Для французьких звуків обираються вже наявні кириличні літери з інших мов, якщо їхнє засвідчене звукове значення точніше й читабельніше за українську літеру з кількома діакритиками.

| Графема UFPN | IPA | Звідки взято | Пояснення |
|---|---|---|---|
| `ў` | /w/ | білоруська | Нескладове `ў`; відрізняє /w/ від /v/ |
| `ү` | /y/ | казахська | Передній високий огублений голосний |
| `ӧ` | /ø/ | марійська | Передній напівзакритий огублений голосний |
| `ӧ̆` | /œ/ | марійська основа + знак відкритості | Передній напіввідкритий огублений; лише один додатковий знак |
| `ӹ` | /ə/ | гірськомарійська | Редукований центральний голосний |
| `э` | /ɛ/ | російська/білоруська | Передній напіввідкритий неогублений |
| `њ` | /ɲ/ | сербська | Одна літера для піднебінного носового; не плутати з українським `нь` = [nʲ] |
| `ң` | /ŋ/ | казахська | Велярний носовий |
| `ғ` | /ʁ/ | казахська | Дзвінкий увулярний щілинний; замінює колишнє `х̬̠` |
| `ү̯` | /ɥ/ | UFPN-комбінація | Нескладовий відповідник /y/ з огубленням; один знак нескладовості |

`ы` не призначено для /ə/: російське [ɨ] не є французьким schwa. `ё` не призначено для /ø/ чи /œ/: воно має йотоване/контекстне значення. Джерела для запозичених відповідностей: S31–S36 у [реєстрі джерел](SOURCE-REGISTRY.md).

Машинозчитувані записи та походження графем містяться в `data/ufpn-mapping.json` → `graphemeInventory`. Запозичення графеми не переносить у французьку мову правила орфографії чи фонології мови-джерела.

## Таблиця «літера — звук — українське слово»

У вебсервісі ця таблиця відкрита за замовчуванням і містить усі 37 сегментних одиниць. Для кожного звука вказано один із чотирьох статусів: точний український звук, позиційний алофон, лише наближений звук або відсутність точного відповідника. Не слід видавати [nʲ] у слові «кінь» за французький [ɲ], а українське [x] — за дзвінкий увулярний [ʁ]. Коли відповідника немає, таблиця прямо це зазначає.

## Рівні

- **Basic:** український запис сегментів; зберігає фонемні розрізнення broad IPA, але не кожну передбачувану алофонічну деталь. Не показує межі складів, довготу чи просодію. Не зливає /œ̃/ з /ɛ̃/ самостійно.
- **Detailed:** додає межу складу ·, довготу ː/ˑ і зв'язування ‿, якщо вони є у вхідному IPA.
- **Extended:** додає вузькі IPA-модифікатори, ˈ/ˌ, межі ритмічних груп ‖ та контури ↗/↘ лише з фонетичної/аудіоанотації.

## Важливі обмеження

1. **х̬̠** — практичний український наближений запис дзвінкого заднього ротичного фрикативного /ʁ/, а не твердження про тотожність українському [х] або [р]. Пояснення має показувати увулярне місце творення.
2. **нь** — читабельна графічна апроксимація /ɲ/; Extended має зберігати відмінність від [nj] та [n].
3. **нґ** — атомарний диграф для периферійного /ŋ/ у запозиченнях; це не послідовність /nɡ/ у фонетичному рушії.
4. /ɑ/ та /œ̃/ збережені в таблиці, хоча для багатьох сучасних мовців відповідні протиставлення нейтралізовані.
5. Градієнтна назалізація й коартикуляція не отримують знака в Basic. Для Extended потрібна вузька IPA-форма чи аудіодані.
6. Набір потребує незалежної перевірки українським фонетистом і тестування читабельності з україномовними користувачами.

## Технічні правила

- Нормалізація виходу: Unicode NFC.
- Обробка — за графемними кластерами, не за UTF-16 code units.
- Базові літери UFPN відображаються Charis SIL; діакритики у вебінтерфейсі більше не покладаються на OpenType-якорі шрифту. `src/ufpn-display.js` розкладає кожен графемний кластер на базову літеру й окремі spacing-modifier glyphs, які CSS позиціонує явно над/під основою. Це presentation layer: канонічний Unicode-вихід, IPA→UFPN mapping і копіювання не змінюються. Візуальне приймання в реальному браузері ще потрібне.
- Комбіновані знаки залишаються Unicode combining marks, а не перетворюються на окремі пробіли чи псевдографеми; порядок і фонетичне значення діакритиків не змінюються заради верстки.
- Невідомий IPA не зникає: виводиться як ⟦…⟧ і повертається в unsupported.
- Для копіювання/пошуку текст можна нормалізувати в NFC; оригінальний вхід зберігається окремо.
- Заборонено створювати французька-графема → UFPN шлях: лише IPA → UFPN.

У реєстрі також є окремі allophoneMappings для варіантів /ʁ/ (увулярні фрикативні/апроксимантні/тремтливі та регіональні альвеолярні реалізації). Для [ʀ] спосіб творення збережено в provenance, але окремий читабельний UFPN знак ще не затверджено.

Машинозчитувана специфікація: data/ufpn-mapping.json.

## Фонетичні характеристики поза базовою таблицею

Машинозчитуваний featureDimensions перелік охоплює висоту/передність голосних, огублення, назальність, тривалість, дифтонгізацію, місце й спосіб творення приголосних, фонацію, вторинну артикуляцію, асиміляцію, просодію та соціофонетичну варіантність. Статус кожного виміру вказує, чи він закодований у Basic, доступний лише в Extended, потребує аудіо або лишається дослідницьким.

## Алофонічні композити та Extended-only ознаки

- [t͡s]/[d͡z] (або tie bar під рядком) мають окремі Québec-профільні композитні записи т͡с/д͡з; вони не є фонемами базового Metropolitan інвентарю.
- [n͡ŋ] у Extended передається н͡нґ, але Basic/Detailed зберігають н, бо дослідження описує градієнтне перекриття жестів, а не категоричну зміну фонеми.
- [s̬]/[z̥] у Extended показують спостережену асиміляцію; Basic/Detailed не змінюють базову фонему.
- [ʀ] поки не має окремого затвердженого UFPN маркера тремтіння; це явний PARTIAL, не прихована втрата.


## Розширені фонетичні модифікатори

Ці знаки не є окремими UFPN-базовими графемами; Extended передає їх лише якщо вони вже наявні у вузькому IPA або підтверджені аудіо:

| Знак | Значення | Умова |
|---|---|---|
| ʰ | придих | лише спостережена реалізація; не типовий default для французьких проривних |
| ◌̚ | нерелізований зімкнений | аудіодоказ |
| ◌̩ | складотворчий приголосний | фонетичне/складове маркування |
| ◌̤ / ◌̰ | придихова / скрипуча фонація | акустичне підтвердження |
| ◌̹ / ◌̜ | сильніше / слабше огублення | вузька транскрипція |
| ˠ / ˤ / ˞ | веляризація / фарингалізація / ротичність | лише підтверджений вузький IPA |
| ⁿ / ˡ | носовий / боковий випуск зімкненого | аудіодоказ |

Це повний каталог розглянутих модифікацій для поточної версії; він не стверджує, що кожна з них типова або контрастивна у французькій мові.
